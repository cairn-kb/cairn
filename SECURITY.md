# Security

Please report vulnerabilities privately through GitHub's
**Report a vulnerability** button on this repository (Security tab), not in a
public issue. If the button is missing, email 0xQwertic@proton.me. We aim to
acknowledge within three working days.

This covers the CLI, the installer and `@cairn-kb/protocol`. Issues in the
hosted team service can be reported the same way.

Only the latest release is supported.
